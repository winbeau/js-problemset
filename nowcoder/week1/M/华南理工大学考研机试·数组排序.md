# 华南理工大学考研机试·数组排序

## 题目描述

输入个数不限的数字，以逗号为分隔，以回车键为结束，数字大小在 $[-32768, 32767]$ 之间。从小到大排序后以 $4$ 个数每行输出。

## 输入描述

如题目描述

### 数据范围

数字个数不限，但每个数字的大小在 $[-32768, 32767]$ 之间。

## 输出描述

如题目描述

## 样例1

### 输入

```
12,34,-12,23,123,56,-9,789
```

### 输出

```
-12 -9 12 23
34 56 123 789
```
