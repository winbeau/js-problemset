# 中南大学保研机试·回文串问题

## 题目描述

“回文串”是一个正读和反读都一样的字符串，字符串由数字和小写字母组成，比如“level”或者“abcdcba”等等就是回文串。

请写一个程序判断读入的字符串是否是“回文”。

## 输入描述

输入包含多个测试实例，每一行对应一个字符串，串长最多100字母。

### 数据范围

字符串长度不超过100，且仅由数字和小写字母组成。

## 输出描述

对每个字符串，输出它是第几个，如第一个输出为"case1: "；如果一个字符串是回文串，则输出"yes",否则输出"no"，在yes/no之前用一个空格。

## 样例1

### 输入

```
level
abcde
noon
haha
```

### 输出

```
case1: yes
case2: no
case3: yes
case4: no
```
