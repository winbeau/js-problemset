# 能否排序

## 题目描述

给定一个长度为 $n$ 的数组，数组中的每个元素都有一个属性值（$0$ 或 $1$）,只有属性值不同的两个元素才能交换两个元素的位置，问能否通过交换元素的位置使得元素有序。

（$n \leq 1e5$）

## 输入描述

先输入一个 $t$，表示测试样例数量，每组首先输入一个 $n$ 表示序列的长度，第二行输入 $n$ 个数为原始序列，第三行 $n$ 个数表示第 $a[i]$ 个的属性。

## 输出描述

其他描述: $Yes$ 或 $No$

## 样例1

### 输入

```
1
5
1 8 9 4 7
0 1 1 0 0
```

### 输出

```
Yes
```
