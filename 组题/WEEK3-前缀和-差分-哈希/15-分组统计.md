# 分组统计

## 题目描述

给定 $n$ 个整数 $a_1$，$a_2$，…，$a_n$，这 $n$ 个数对应 $m$ 个不同的数值，从小到大依次为 $v_1$，$v_2$，…，$v_m$。

（$m \leq n$）

这 $n$ 个数被分到了 $k$ 个小组中。

$k$ 个小组编号 $1 \sim k$ 且每个小组都不为空。

现在，请你统计每个小组中，每个数值的数有多少个。

## 输入描述

第一行包含整数 $T$，表示共有 $T$ 组测试数据。

每组数据第一行包含整数 $n$，表示整数个数。

第二行包含 $n$ 个整数 $a_1$，$a_2$，…，$a_n$

第三行包含 $n$ 个整数，其中第 $i$ 个整数表示 $a_i$ 所在的小组编号。

### 数据范围

$1 \leq T \leq 10$

$1 \leq k \leq n \leq 100$

$1 \leq a_i \leq 1000$

## 输出描述

每组数据输出 $k$ 行，第 $i$ 行输出第 $i$ 组的各数值统计情况，格式如下：

```

i={v_1=xx,v_2=xx,...,v_m=xx}

```

具体可参照样例。

## 样例1

### 输入

```
1
7
3 2 3 8 8 2 3
1 2 3 2 1 3 1
```

### 输出

```
1={2=0,3=2,8=1}
2={2=1,3=0,8=1}
3={2=1,3=1,8=0}
```
