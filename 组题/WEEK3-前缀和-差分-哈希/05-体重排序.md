# 体重排序

输入 $ n $ 个姓名和这个人对应的体重，输出体重从小到大的**名字**。

如果体重相同，按字典序先后输出名字。

#### 数据范围

```

0≤n≤10000

```

#### 输入样例

```
4
Li 50.12
Ming 43.12
Dan 75
Tia 43.12
```

#### 输出样例

```
Ming Tia Li Dan
```
