## 花了多少钱-深圳大学

#### 题目描述

笔记本每本价格为 ${a}$ 元（${a}$ 为正整数），小明购买了 ${b}$ 本（${b}$ 为正整数）。请问小明总共花了多少钱？

#### 输入格式

一行输入两个正整数 ${a}$ ${b}$，表示笔记本的价格和购买数量

#### 输出格式

输出一个整数，表示小明花费的总金额

#### 数据范围

${1 \le a, b \le 1000}$

#### 输入样例

```
5 3
```

#### 输出样例

```
15
```

## 投票选举-深圳大学

#### 题目描述

对候选人得票的统计程序。设有3个候选人，每个选民投票输入一个得票的候选人的名字，要求最后输出各人得票结果。

三个候选人的名字分别为`Li Zhang Fu`。

#### 输入格式

第一行输入选票数 $n$ 

第二行起输入 $n$ 行，每行是一个候选人名字

#### 输出格式

输出三个候选人的统计结果，格式为：`候选人名字:得票数`

输出顺序固定为：Li、Zhang、Fu

#### 数据范围

- 选票数n满足 1 ≤ n ≤ 100

- 候选人名字可能包含不在三个候选人中的名字，这些选票视为无效票

#### 输入样例

```
5
Li
Fu
Fu
Zhao
Bai
```

#### 输出样例

```
Li:1
Zhang:0
Fu:2
```

## 预约资格判定-深圳大学

#### 题目描述

某驾驶的预约资格是：在每 ${12}$ 天的周期内，总学时达到 ${10}$ 小时可以预约考科目 ${2}$。

练习每一小时计一学时，不足一小时计 ${0}$。

受限制，按实际练车时长计算学时（若练车不足一小时则不算一学时，例如练车 ${119}$ 分钟只算练车 ${1}$ 小时计 ${1}$ 学时）。

#### 输入格式

第一行输入 ${t}$，表示有 ${t}$ 个学员。

每个学员输入两行：

- 第 ${1}$ 行输入学员姓名和学员类型，其中学员类型用单个大写字母表示，${N}$ 表示普通学员，${V}$ 表示 VIP 学员。

- 第 ${2}$ 行输入 ${12}$ 天的每天练车时间（单位为分钟）。

依次类推输入下一个学员。

#### 输出格式

输出 ${t}$ 行，每行输出学员姓名和是否可以预约科目二，具体输出信息看样例

#### 数据范围

- ${t}$ 为整数，且 ${1 \leq t \leq 100}$。

- 学员姓名由字母组成，长度不超过 ${20}$。

- 每天练车时间为整数分钟，且 ${0 \leq \text{分钟数} \leq 1440}$（即不超过 ${24}$ 小时）。

#### 输入样例

```
3  
Wendy N  
30 30 40 60 60 40 60 70 100 80 30 40  
Sarah V  
170 80 90 50 60 90 240 0 40 60 30 166  
zhang V  
80 10 10 30 60 0 60 0 30 150 0 0  
0 10 10 0 0 10 0 20 0 0 150 160
```

#### 输出样例

```
Wendy not qualify  
Sarah qualify  
zhang not qualify
```

## 银行窗口服务-深圳大学

#### 题目描述

在银行营业大厅共服务3种客户，类型为A、B、C。大厅分别设置了3个窗口分别服务三种客户，即每个窗口只服务一种客户。

现有一批客户来银行办理业务，每个客户都有类型和办理时间。每个窗口按照客户到来的顺序进行服务。

请使用C++的queue队列实现该程序。

#### 输入格式

第一行输入 $n$ 表示客户数量。

第二行输入客户类型序列，数据之间用空格分隔

第三行输入每个客户的办理时间序列，数据之间用空格分隔

#### 输出格式

第一行输出A类客户的平均办理时间

第二行输出B类客户的平均办理时间  

第三行输出C类客户的平均办理时间

所有结果仅保留整数部分

#### 数据范围

客户数量不超过1000

办理时间为正整数

#### 输入样例

```
8
A B C B C A A A
10 20 30 40 50 60 70 80
```

#### 输出样例

```
55
30
40
```

## DNA序列-深圳大学

#### 题目描述

两个等长字符串的 $Hamming$ 距离等于字符不同的位置个数。例如，${ACGT}$ 和 ${GCGA}$ 的 $Hamming$ 距离为 ${2}$（左数第 ${1}$、${4}$ 个字符不同）。

输入 ${m}$ 个等长的 $DNA$ 序列，求其中的某个 $DNA$ 序列，到其它 ${m-1}$ 个序列的总 $Hamming$ 距离最小。注意：如有多解，要求字典序最小的解。

例如，对于下面 ${3}$ 个 DNA 序列：

```

3

ATTGC

ACTGT

TCCGC

```

其中：${TCCGC}$ 到 ${ATTGC}$ 的 $Hamming$ 距离是 ${3}$，到 ${ACTGT}$ 的 $Hamming$ 距离是 ${3}$，因此它到其它序列的总 $Hamming$ 距离和是 ${6}$。同理，${ATTGC}$ 和 ${ACTGT}$ 到其它序列的总 $Hamming$ 距离和都是 ${5}$，按字典序，则最优解为 ${ACTGT}$。

#### 输入格式

第一行输入 DNA 数目 ${m}$。

其余各行，依次输入 ${m}$ 个等长的 DNA 序列。

#### 输出格式

输出到其余 ${m-1}$ 个序列的 $Hamming$ 距离和最小的 DNA 序列，以及该总距离。

#### 数据范围

- ${1 \leq m \leq 50}$

- 每个 DNA 序列长度不超过 ${500}$，且仅由字符 ${'A'}$、${'C'}$、${'G'}$、${'T'}$ 组成。

#### 输入样例

```
3
ATTGC
ACTGT
TCCGC
```

#### 输出样例

```
ACTGT 5
```

## 带哨兵的顺序查找-深圳大学

#### 题目描述

给出一个队列和要查找的数值，找出数值在队列中的位置（位置从1开始）。

要求使用带哨兵的顺序查找算法：把要查找的数值插入到队列头部作为哨兵，然后从队列末尾往前查找。如果在队列中找到则返回位置，如果查找不成功则输出"error"。

#### 输入格式

第一行输入整数 ${n}$，表示队列有 ${n}$ 个数据

第二行输入 ${n}$ 个正整数，用空格隔开

第三行输入整数 ${i}$，表示要查找的数值个数

接下来输入 ${i}$ 行，每行一个要查找的数值

#### 输出格式

输出 ${i}$ 行，每行输出一个查找结果（位置或"error"）

#### 数据范围

${1 \le n \le 1000}$

${1 \le i \le 100}$

#### 输入样例

```
8
33 66 22 88 11 27 44 55
3
22
11
99
```

#### 输出样例

```
3
5
error
```
