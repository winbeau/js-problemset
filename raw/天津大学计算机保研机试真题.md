```

5
```

## 跳着数数-天津大学



#### 题目描述

小 $Z$ 不喜欢 $0$ — $9$ 中较大的数字，他想知道如果去掉所有包含大数字的数之后 $[1, n]$ 区间内还剩多少个数。  

例如，小Z不喜欢 $7, 8, 9$ 三个数字，将所有任意位存在这三个数字的数去掉后，$[1, 12]$ 中只剩下了 $[1, 2, 3, 4, 5, 6, 10, 11, 12]$ 这 $9$ 个数。  

注意，$9, 19, 190$ 都包含数字 $9$，在计数时都需要删去。

#### 输入格式

多组样例输入，第一行输入一个整数 $T$ 表示样例数。

对于每个样例，包含两个数字 $n$ 和 $k$，$n$ 表示需要在 $[1, n]$ 内进行统计，$k$ 表示小 $Z$ 不喜欢的数字为 $[k, 9]$。

#### 输出格式

对于每组样例，输出一个数字表示删除不喜欢的数后剩余数字的数量。

#### 数据范围

$n \leq 10^{18}$

$1 \leq k \leq 9$

#### 输入样例

```
2
12 7
100 5
```

#### 输出样例

```
9
25
```

所有相同且连续的字符串将被压缩成 $“连续个数 + 原字符”$ 的形式，例如字符串 $“AaaaBC”$ 将被压缩为 $“1A3a1B1C”$，字符串 $“11111AB11”$ 将被压缩为 $“511A1B21”$。

#### 输出格式

对于每一组输入，输出压缩结果。

#### 输入样例
```
3
333 444
    ABCD
TJU 1895
```

#### 输出样例
```
331 34
4 1A1B1C1D
1T1J1U1 11181915
```

## Magical String Conversion-天津大学

#### 题目描述

给定一个字符串，判断它是否为 $magical$ $string$。

计算至少需要进行多少次转换（转换指 $>$ 和 $<$ 之间的互相转换）才能使字符串满足 $magical$ $string$ 的条件。

#### 输入格式

第一行输入一个整数，表示字符串的总行数。

接下来的每一行输入一个字符串，字符串的长度为偶数。

#### 输出格式

对于每个输入的字符串，输出使其成为 $magical$ $string$ 所需的最少转换次数。

#### 输入样例
```
2
>><<<>
>><<
```

#### 输出样例
```
2
0
```
