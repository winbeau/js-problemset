## 最小的没出现的正整数-中国科学院

#### 题目描述

给定一个整数数组，求数组中未出现的最小正整数。

#### 输入格式

输入一行，包含若干个整数，整数之间用空格分隔。

#### 输出格式

输出一个整数，表示未出现的最小正整数。

#### 输入样例

```
3 5 2 1 6 0 -2
```

#### 输出样例

```
4
```

## Z字形变换-中国科学院

#### 题目描述

输入一个整数 `n`，表示输出的行数，再输入一个字符串，输出 Z 字排列后的串。Z 字形排列的过程如下：字符串被以倒 Z 的形状（实际上是正 N 的形状）排列在 `n` 行中，然后按行输出。

例如，输入 `n = 3` 和字符串 `"COMPUTERVISION"`，排列如下：

```

C   U   V   O

 O P T R I I N

  M   E   S

```

按行输出得到：`"CUVOOPTRIINMES"`。

#### 输入格式

第一行输入一个整数 `n`（1 ≤ n ≤ 1000），表示行数。

第二行输入一个字符串 `s`（长度不超过 1000）。

#### 输出格式

输出变换后的字符串。

#### 数据范围

- 1 ≤ n ≤ 1000

- 字符串长度不超过 1000

#### 输入样例

```
3
COMPUTERVISION
```

#### 输出样例

```
CUVOOPTRIINMES
```

## 选择特殊点问题-中国科学院

#### 题目描述

在一条直线上给出$ n $个点的位置，然后从中选出$ k $个特殊点，要求每个点到离它们最近的特殊点的距离之和最小。

然后给出这个最小的距离。

#### 输入格式

第一行包含两个整数$ n $和$ k $，表示点的数量和需要选择的特殊点数量。

第二行包含$ n $个整数，表示每个点的位置。

#### 输出格式

输出一个整数，表示最小的距离之和。

#### 输入样例

```
5 2
1 2 3 4 5
```

#### 输出样例

```
3
```

## 找出两个有序表中的相同数-中国科学院

#### 题目描述

给定两个有序表，找出两个表中相同的数并打印出来。

#### 输入格式

输入包含两行，每行是一个有序表，表中的数按升序排列，数与数之间用空格分隔。

#### 输出格式

输出两个有序表中相同的数，按升序排列，数与数之间用空格分隔。

#### 输入样例

```
1 2 3 4 5
3 4 5 6 7
```

#### 输出样例

```
3 4 5
```

## 糖果分配问题-中国科学院

#### 题目描述

假设有 $n$ 个小朋友，每个人至少要给一个糖果。

同时给出 $k$ 个需求，其中表示了 $x$ 号小朋友要求不能比 $y$ 号小朋友少。

问你最后至少需要多少个糖果才能满足全部的需求，如果没法满足就输出 $-1$。

#### 输入格式

第一行包含两个整数 $n$ 和 $k$，表示小朋友的数量和需求的数量。

接下来 $k$ 行，每行包含两个整数 $x$ 和 $y$，表示 $x$ 号小朋友的糖果数不能比 $y$ 号小朋友少。

#### 输出格式

输出一个整数表示最少需要的糖果总数，如果无法满足需求则输出 $-1$。

#### 输入样例

```
3 2
1 2
2 3
```

#### 输出样例

```
6
```
