# 各大高校计算机考研/保研复试机试真题

收录、整理并开源全国各大高校 **计算机考研复试机试 / 保研上机考试** 的历年真题，包含清华、北大、复旦、上交、浙大、国防科大、中科大、北航、北理、华科等几十所高校，题源持续更新中。

本项目旨在为计算机专业同学提供系统、真实、可练习的复试机试资料，让准备考研复试/保研机试不再盲目。

**题目在不断增加完善中，请不时拉取更新：[仓库地址：https://gitcode.com/u014339447/pgcode](https://gitcode.com/u014339447/pgcode)**


## ✨ 项目特色

- **覆盖院校广**：包含全国数十所高校的机试真题。
- **题目格式统一**：统一转化为可读格式，适配大多数编程环境。
- **可在线刷题**：所有题目均已同步到 **pgcode.cn**，可实时在线编写、运行、评测代码。
- **持续更新**：每周更新最新收集到的题目与解析。
- **社区驱动**：支持 PR，欢迎贡献你们学校的机试真题！

## 🧑‍💻 如何使用

### 1. 本地练习
