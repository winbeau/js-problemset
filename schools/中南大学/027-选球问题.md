# 选球问题

#### 题目描述
小诺现有 a-z 共 26 种球，权值从 a 到 z 依次为 1,2,3...26，现从已有的 ${n}$ 个球中选出固定 ${k}$ 个从左到右排列，要求右边的球权值至少比左边大 2，在给定 ${n}$ 和 ${k}$ 的情况下，求最小权重和。
#### 输入格式
输入包含多组数据。

每组数据第一行包含两个整数 ${n, k}$（${1 \le k \le n \le 50}$），第二行是一个长度为 ${n}$ 的字符串。
#### 输出格式
对于每组样例，输出最小权重和。

若不存在输出 -1。
#### 数据范围
${1 \le k \le n \le 50}$
#### 输入样例
```
5 3
xyabd
```
#### 输出样例
```
29
```
